# AQIprediction

I did this as a project in my ESP300 lab(All AI help)

Workflow:

AQI data downloaded from CPCB website-> Processed through various ml models aqi obtained from the concentrations given in the excel-> the accuracy of the model is checked and simulataneously aqi is predicted for next 72 hours-> this is paired with a matlab code to simulate the working of an air purifier

Improvements:

A display with arduino can be paired to show the actual AQI at that point of time which can be compared to the predicted category and a sort of feedback can eb created for the user
